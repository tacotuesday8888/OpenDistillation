# Notebooks

This directory will hold the Colab-first OpenDistillation demo.

The first notebook should prove one flow:

> Upload a `.txt` or `.md` document, generate training examples, train a small student model, and show the path to local running.

## Planned Notebook

- `opendistillation_v0_demo.ipynb`

## Notebook Principles

- Beginner-readable.
- One main path, not many branches.
- Small defaults.
- Clear outputs after every major step.
- Honest labels for anything that is only a placeholder or future export path.

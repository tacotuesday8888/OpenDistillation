# Start Here

Open this file first when returning to the project.

## What Exists Now

OpenDistillation has a local Git repository with project foundation docs.

It does not have real training code yet.

## What This Project Is

OpenDistillation is intended to be an open-source productized tool:

> Upload docs. Distill a tiny local model. Run it locally.

The first serious version should be Colab-first, not a Mac app or SaaS.
